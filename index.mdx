<div className="mt-16 mb-16 max-w-5xl mx-auto px-6">
  <h2 className="text-2xl sm:text-3xl font-bold text-gray-900 dark:text-white mb-4">
    Get Started in Minutes
  </h2>
  <p className="text-base text-gray-600 dark:text-gray-400 mb-8">
    Deploy your first secure workspace and connect users with SSO authentication
  </p>

  <Steps>
    <Step title="Deploy the infrastructure">
      Clone the repository and configure your environment variables. NeoSC uses Docker Compose for easy deployment.

      ```bash
      git clone https://github.com/infra-neo/NeoSC.git
      cd NeoSC
      cp infra/.env.example infra/.env
      ```

      Edit `infra/.env` to configure your Zitadel SSO credentials and domain settings.
    </Step>

    <Step title="Start the services">
      Launch the full stack including Pomerium reverse proxy, FastAPI backend, React frontend, and MongoDB.

      ```bash
      cd infra
      docker compose up -d
      ```

      <Note>
        The platform will be available at `https://portal.kappa4.com` (or your configured domain). Pomerium handles authentication and proxying.
      </Note>
    </Step>

    <Step title="Configure Zitadel SSO">
      Set up your Zitadel application with the correct redirect URIs and scopes.

      ```yaml
      Redirect URI: https://portal.kappa4.com/auth/callback
      Post Logout URI: https://portal.kappa4.com
      Grant Types: Authorization Code, Refresh Token
      ```

      See the [Zitadel SSO guide](/authentication/zitadel-sso) for detailed configuration steps.
    </Step>

    <Step title="Launch your first workspace">
      Access the dashboard and launch a secure workspace. NeoSC supports Linux, Windows, browser, dev container, and admin desktop environments.

      ```bash
      curl -X POST https://api.portal.kappa4.com/api/workspaces/{id}/launch \
        -H "Authorization: Bearer YOUR_TOKEN"
      ```

      <Accordion title="Example response">
        ```json
        {
          "id": "workspace-123",
          "status": "running",
          "connection": {
            "url": "https://workspace-123.portal.kappa4.com",
            "tunnel_status": "encrypted"
          }
        }
        ```
      </Accordion>
    </Step>
  </Steps>
</div>
